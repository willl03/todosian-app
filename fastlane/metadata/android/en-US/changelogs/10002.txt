Second fork release, based on upstream 2.2.

New Features:
• Folder widgets - bind a widget to a whole folder; the header shows the folder name and its lists appear with small headers, in your manual order
• The widget's add button follows its binding - a folder widget opens the picker scoped to that folder's lists, and the full picker mirrors the folder structure
• Task notes - a one-line note per task (edited in the add/edit sheet, shown above the task's metadata in the list), with clickable links
• Todoist-style priorities - P1 (red), P2 (yellow), P3 (blue), P4 (default), consistent in light and dark themes

Improvements:
• Recolored launcher icon (red on black) with an optically centered logo
• Cleaner task editor - start, scheduled, and recurrence fields removed; the completion date shows only when editing completed tasks
• The creation date no longer appears in the task footer
• Moving or copying a todo shows the folder structure instead of a flat list
• Move and Delete moved behind a long press on a todo; swipe gestures removed
• Deleting a list returns to the folder view
• The due-date field is now labeled "Date", and the sort option is "Date (first) + Priority (second)", moved to the bottom of the list
